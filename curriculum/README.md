# Curriculum

The Soccer-Academy curriculum and the knowledge it's built from.

> **📏 All documents here follow the [Documentation Standard](DOC_STANDARD.md):
> zero invention (every number/standard/formula from a real, cited source), and
> where sources differ, adopt the higher standard.** Read it before adding content.

## Structure

| Area | What it is |
|---|---|
| **[`DOC_STANDARD.md`](DOC_STANDARD.md)** | integrity rules for every doc here (**read first**) |
| **[`index/`](index/README.md)** | the knowledge index — the *building blocks* (skills, moves, tactics, attributes, metrics, laws, teaching cues) |
| **[`research/`](research/README.md)** | academy model research (Benfica, La Masia, Ajax) + the merged model — the *how* |
| **[`age-08/`](age-08/README.md)** | the age-8 curriculum (first of the 8→13 age-by-age build) |

## How it fits together

1. The **index** lists every building block to cover.
2. The **merged model** (research) says how to teach them.
3. Each **age unit** (8→13) sequences the age-appropriate blocks, taught the
   merged-model way, with benchmarks grounded per the Documentation Standard.
