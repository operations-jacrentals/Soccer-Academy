Age-8 drill animations — reusable library

Self-contained, skin-agnostic SVG+CSS coaching animations for the age-8 drills. Colours come from CSS custom properties on :root (swap them for any UI theme). The shared ball/foot symbols are defined once and referenced by every sketch via <use href="#ball">. The framework: animate the jargon, not the plain English — only soccer lingo/moves get a sketch. Motion respects prefers-reduced-motion. 47 sketches.
