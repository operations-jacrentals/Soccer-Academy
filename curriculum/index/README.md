# Soccer Knowledge Index

A comprehensive, curriculum-facing index of the game of soccer. It catalogs the
**full landscape** — every skill, move, drill, attribute, tactic, metric, and
idea — as a reference we draw from when laying out the Academy curriculum.

> **This is an index, not the curriculum.** Entries are broad and concise on
> purpose. Depth, age-sequencing, and session plans come *later*, when we map
> these items onto the curriculum. This file is the map; the curriculum is the
> route.

## Tagging legend

Every catalog entry can carry these tags so it maps cleanly to curriculum design.

**Difficulty tier**
- `F` — Foundational (first exposure; base technique)
- `I` — Intermediate (reliable under mild pressure)
- `A` — Advanced (executed at speed, under real pressure)
- `E` — Elite (match-defining, high-consistency mastery)

**Four Corners** (the FA player-development model — every player is developed across all four)
- `[T]` Technical / Tactical — what to do with and around the ball
- `[P]` Physical — the body: speed, strength, endurance, coordination
- `[Ps]` Psychological — the mind: focus, confidence, resilience, decisions
- `[S]` Social — the person: communication, teamwork, character, discipline

**LTAD stage** (Long-Term Athlete Development — see [11](11-player-development-and-pathways.md))
- `FUN` FUNdamentals (~6–9) · `L2T` Learn to Train (~9–12, the "golden age")
- `T2T` Train to Train (~12–16) · `T2C` Train to Compete (~16+)

**Position relevance** — `GK · DEF · MID · FWD · ALL`

Example entry: **La Croqueta** — quick two-touch shift of the ball across the
body to escape a lunging defender. `I` `[T][P]` `L2T` `MID·FWD`

## How to use this for curriculum design

1. **Pick outcomes** from the index for a given age/LTAD stage (filter by tier + stage tag).
2. **Balance the four corners** — a good session/block touches `[T] [P] [Ps] [S]`, not just the ball.
3. **Sequence** foundational → intermediate → advanced within each strand.
4. **Choose a method** from [03](03-training-methodology-and-drills.md) to teach each outcome.
5. **Define measures** from [09](09-metrics-and-statistics.md) to know it's landing (age-appropriately).

## Maintaining the index

This lives in the repo and evolves through the normal workflow: branch → PR →
review. Add entries where they fit, keep the tagging consistent, and prefer
adding a concise catalog line over a long essay — depth belongs in the
curriculum, not the index.
